# 基米翻译 · Jimi Translator

**一个简洁、好用的屏幕翻译器：读屏幕、只翻新出现的段落、译文浮在原处。英译中 / 中译英双向。**

用途很杂：论文（理工科 / 医学 / 人文都行）、教材、网页、软件界面、聊天记录、英文资料都行。默认自动识别方向——屏幕上英文就出中文，屏幕上中文就出英文。内置一份强化学习 / 机器人方向的术语表作为默认偏好，也可以整段替换提示词、追加自己的领域术语。

不注册、不登录、没有云端；一个 60 KB 的 APK，装完就能用。

> 📱 单 APK，约 60 KB；不需要 root，不需要电脑，不需要登录任何账号（自带你自己的模型 API key）。

## 它长什么样

- 一个**可拖动的橙色猫猫圆钮**浮在屏幕上，点开是一张译文卡；
- 点「**框选**」→ 屏幕变暗，手指拖一个矩形 → 只翻你圈的那块；
- 点「**自动**」→ 整屏跟读：你往下滚，它只翻**新出现**的段落，翻过的不会重复；
- 「**中英**」开关决定译文上方是否显示原文；
- 设置里可选「**翻译方向**」：自动识别 / 英译中 / 中译英；
- 「不透明度」滑杆控制卡片底色深浅，**文字颜色和粗细会跟着反向变化**（背景越透 → 字越黑越粗），保证任何底色下都看得清。

```
┌─────────────────────────────┐
│ 基米翻译   待机      不透明度 │
│ 框选  自动  中英  清空  收起  │
├─────────────────────────────┤
│ To encourage policies to …   │  ← 可选英文原句
│ 为了鼓励策略保持随机性并更有效│
│ 地探索，标准目标中加入了熵项…│
│ …                            │
├─────────────────────────────┤
│ 新增 12 段 · 跳过重复 3       │
└─────────────────────────────┘
```

## 安装

1. 下载 `JiMi-vX.Y.apk`（Releases 页），传到手机上点开安装，允许「未知来源」；
2. 打开 App，填**模型 API key**（默认 DeepSeek：`https://api.deepseek.com/v1` + `deepseek-flash`，需支持图片输入）；
3. 点「权限设置（开启无障碍服务）」→ 系统设置里打开「**基米翻译 · 读屏服务**」；
4. 浮窗出现，开翻。

### 必需权限

| 权限 | 用途 | 说明 |
|---|---|---|
| 无障碍服务 | 截取屏幕画面 | 系统级服务，只用来 `takeScreenshot`，不读聊天记录、不模拟点击 |
| 悬浮窗 | 显示译文卡片 | 用的是无障碍悬浮层，**不需要**额外的「显示在其他应用上层」 |

> ⚠️ 每次安装新版本，系统都会把无障碍服务解绑，需要重新打开一次。若发现服务被系统反复关闭，请把基米翻译的电池策略设为「不限制」，并在最近任务里锁定它。

## 工作原理（30 秒版）

```
屏幕截图 ──► 画面指纹（32×24 灰度）──► 没变？跳过，不花模型钱
   │
   ├─ 变了 ──► 画框选标记 / 裁选区 ──► 视觉模型（流式）
   │                                        │
   │                            JSON 流式分片，凑齐一段显示一段
   │                                        ▼
   └──────────────────────────► 句子级去重（归一化 + Jaccard）──► 悬浮窗
```

几个关键设计：

- **只翻新内容**：每次请求都带上「已翻译过的英文句子」清单（最近 26 条），模型只输出清单外的段落；本地再做一道句子级去重，兜住 PDF 滚动造成的半句重叠。
- **不重复花 token**：截图后先算 32×24 灰度指纹，画面没动就直接跳过（手动点「框选」不受此限制）。
- **段序稳定**：要求模型给每段编号 `i`（从 1 开始、对应截图从上到下），客户端按 `i` 排序后再显示，模型输出顺序抖动也不影响阅读。
- **流式 + 截断抢救**：SSE 分片一到就解析，已闭合的 `{en, zh}` 立即显示；即使输出被 max_tokens 截断，也能用正则把完整段落捞回来。

细节见 [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)，提示词设计见 [docs/PROMPTS.md](docs/PROMPTS.md)。

## 配置项

| 设置 | 默认 | 说明 |
|---|---|---|
| 接口地址 | `https://api.deepseek.com/v1` | 任何 OpenAI 兼容接口 |
| 模型名 | `deepseek-flash` | 必须支持图片输入 |
| 自动跟读间隔 | 8000 ms | 画面没动时会自动退避到 16s / 20s |
| 系统提示词 | 内置 | 可整段替换，改翻译风格 |
| 自定义术语库 | 空 | 每行 `英文 中文`，优先级高于内置术语表 |
| 流式输出 | 开 | 边生成边显示 |
| 精译模式 | 关 | 开思考模式，慢但更准（输出上限 8K） |
| 哈基米风格浮窗 | 关 | 浮窗主色从蓝变橙 |

## 常见问题

**Q：无障碍服务总是被系统关掉？**
A：Android/ColorOS 会主动关闭第三方无障碍服务，尤其是 App 更新后、或电池优化冻结后台时。把电池策略设为「不限制」，最近任务里锁定 App；更新 APK 后手动重开一次。

**Q：框选不完整就翻不出来？**
A：v1.20 起框选会同时发**两张图**：放大后的选区（只翻这张）+ 整屏截图（只作上下文），并且选区自动外扩 16dp，半行字也能补全。

**Q：一次「自动」翻得太少？**
A：提示词要求整屏有多少段翻多少段，输出上限 16K tokens；如果这一页正文本来就少，它不会凭空造内容。

**Q：译文里出现 `$\mathcal{D}$` 这种 LaTeX？**
A：提示词明确要求公式写普通字符；如果模型还是漏出来，把截图发 issue。

## 目录

```
app/                       Android 应用（标准 Gradle 布局，Java）
  src/main/java/…          MainActivity / 无障碍服务 / 悬浮窗 / 模型调用 / 去重
  src/main/res/            图标、无障碍配置、字符串
  build.gradle.kts         命名空间 / 版本 / 可选环境变量签名
scripts/build-apk.sh       不依赖 Gradle 的手写构建（aapt2 + javac + d8 + apksigner）
docs/                      架构、提示词、构建说明
extras/dsh-plugin/         早期 DSH 网页插件原型，保留作参考
.github/                   CI（构建 APK + 打 tag 自动发 Release）、issue 模板
```

`extras/dsh-plugin/` 是同一套「读屏 → 视觉模型 → 去重 → 浮窗」逻辑的网页版实现，跑在 DeepSeek Harness 里，也能独立部署一个极简翻译页（`/rl-translator`）。它依赖 DSH 的内部服务，不建议单独使用，留作参考。
