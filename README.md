# 基米翻译 · Jimi Translator

**一个简洁、好用的屏幕翻译器：读屏幕、只翻新出现的段落、译文浮在原处。英译中 / 中译英双向。**

论文、教材、网页、软件界面、聊天记录——屏幕上是什么就翻什么。默认「双向」：英文出中文，中文出英文。内置一份强化学习 / 机器人方向的术语表作为默认偏好，也可以整段替换提示词、追加自己的领域术语。

不注册、不登录、没有云端；一个约 66 KB 的 APK，装完就能用（自带你自己的模型 API key）。

## 它长什么样

一个**可拖动的橙色猫猫圆钮**浮在屏幕上，点开是一张译文卡：

```
┌──────────────────────────────┐
│ 基米翻译   待机       不透明度 │
│ 框选  自动  双向  清空  收起  │
├──────────────────────────────┤
│ To encourage policies to …    │  ← 原文（可选）
│ 为了鼓励策略保持随机性并更有效 │
│ 地探索，标准目标中加入了熵项… │
├──────────────────────────────┤
│ 新增 12 段 · 跳过重复 3        │
└──────────────────────────────┘
```

| 按钮 | 作用 |
|---|---|
| **框选** | 屏幕变暗，拖一个矩形，只翻这块 |
| **自动** | 整屏跟读：你往下滚，只翻新出现的段落（再点停止） |
| **双向 / 英译中 / 中译英** | 每点一次循环切换翻译方向 |
| **清空** | 清掉已翻记录与去重表，重新开始 |
| **收起** | 缩成猫猫圆钮（可拖动） |
| **不透明度** | 展开后调背景深浅；同一行还有「显示原文 · 开/关」 |

文字颜色和粗细会跟着透明度反向变化（背景越透 → 字越黑越粗），任何底色下都看得清。

## 安装

1. 下载 `jimi-translator-vX.Y.apk`（[Releases](https://github.com/OnGlacier/jimi-translator/releases)），允许「未知来源」安装；
2. 打开 App，填模型 API key（默认 DeepSeek：`https://api.deepseek.com/v1` + `deepseek-flash`，需支持图片输入）；
3. 点「权限设置（开启无障碍服务）」→ 打开「**基米翻译 · 读屏服务**」；
4. 浮窗出现，开翻。

### 用到的权限

| 权限 | 用途 |
|---|---|
| 网络 | 调用你自己配置的模型接口 |
| 无障碍服务 | 截取屏幕画面（只调用 `takeScreenshot`，不读聊天记录、不模拟点击） |
| 无障碍悬浮层 | 显示译文卡片（不需要额外的「显示在其他应用上层」） |

除此之外不需要任何权限：没有通知、没有电池优化豁免、没有存储、没有后台自启。

> ⚠️ 每次安装新版本，系统都会解绑无障碍服务——这是 Android 的行为，需要重新打开一次。

## 无障碍服务被系统关掉怎么办

ColorOS / HyperOS 这类系统在「清理后台」时会把第三方无障碍服务一起关掉，表现就是「一关 App 就得重新开权限」。

**这个 App 不申请任何额外权限去对抗系统**——它是轻量工具，做法就是：

1. 被关掉后，去「设置 → 无障碍 → 基米翻译 · 读屏服务」重新打开一次；
2. 不想被频繁清理的话，把 App 的电池策略设为「不限制」，并在最近任务里下拉锁定。

> 每次安装新版本，系统都会解绑无障碍服务，也要重开一次——这是 Android 行为。

### 进阶：理论上可以用 Shizuku 做到「自动恢复」

Android 不允许 App 自己重新打开自己的无障碍服务，但允许它**写回系统设置**——前提是先拿到
`WRITE_SECURE_SETTINGS`。拿到的方式是用 Shizuku（或 ADB / root）以 shell 身份执行一次：

```bash
pm grant com.rltranslator.overlay android.permission.WRITE_SECURE_SETTINGS
```

之后 App 就能在发现读屏被关掉时把开关写回去，做到「打开 App 即恢复」。

**本项目没有内置这套逻辑**：它是轻量工具，不想为此申请额外权限、加常驻服务、或依赖 Shizuku。
如果确实需要，可以在历史里找到尝试过的实现（tag `v1.38` 的 `ShizukuHelper` / `A11y` 两个类，
当时因启动崩溃回退），自行改造；也可以只按上面的命令授权后，写一个几十行的自定义版本。

## 工作原理（30 秒版）

```
屏幕截图 ──► 画面指纹（32×24 灰度）──► 没变？跳过，不花模型钱
   │
   ├─ 变了 ──► 画框选标记 / 裁选区 ──► 视觉模型（流式）
   │                                        │
   │                            JSON 流式分片，凑齐一段显示一段
   │                                        ▼
   └──────────────────────────► 句子级去重（归一化 + Jaccard）──► 悬浮窗
```

- **只翻新内容**：每次请求都带上「已翻译过的原文句子」清单（最近 26 条），模型只输出清单外的段落；本地再做一道句子级去重，兜住滚动造成的半句重叠。
- **不重复花 token**：截图先算 32×24 灰度指纹，画面没动就跳过（手动框选不受限）。
- **段序稳定**：模型给每段编号 `i`（从 1 开始、对应截图从上到下），客户端按 `i` 排序显示。
- **流式 + 截断抢救**：SSE 分片一到就解析，已闭合的段落立即显示；即使被 `max_tokens` 截断，也能用正则把完整段落捞回来。

细节见 [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)，提示词设计见 [docs/PROMPTS.md](docs/PROMPTS.md)。

## 配置项

| 设置 | 默认 | 说明 |
|---|---|---|
| 接口地址 | `https://api.deepseek.com/v1` | 任何 OpenAI 兼容接口 |
| 模型名 | `deepseek-flash` | 必须支持图片输入 |
| 翻译方向 | 双向 | 双向 / 英译中 / 中译英（浮窗里也能切） |
| 自动跟读间隔 | 8000 ms | 画面没动时自动退避到 16s / 20s |
| 系统提示词 | 内置 | 可整段替换，改翻译风格 |
| 自定义术语库 | 空 | 每行 `英文 中文`，优先级高于内置 |
| 流式输出 | 开 | 边生成边显示 |
| 精译模式 | 关 | 开思考模式，慢但更准（输出上限 8K） |
| 哈基米风格浮窗 | 关 | 浮窗主色从蓝变橙 |

## 从源码构建

不依赖 Gradle，用 SDK 命令行工具手搓 APK，详见 [docs/BUILD.md](docs/BUILD.md)：

```bash
export ANDROID_HOME=/path/to/android-sdk
bash scripts/build-apk.sh     # 产出 build/app.apk
```

也可以直接用 Android Studio 打开根目录（标准 Gradle 工程，零第三方依赖）。

## 常见问题

**Q：框选不完整就翻译不出来？**
A：框选会同时发**两张图**：放大后的选区（只翻这张）+ 整屏截图（只作上下文），选区还会自动外扩 16dp，半行字也能补全。

**Q：一次「自动」翻得太少？**
A：提示词要求整屏有多少段翻多少段，输出上限 16K tokens；这一页正文本来就少时，它不会凭空造内容。

**Q：译文里出现 `$\mathcal{D}$` 这种 LaTeX？**
A：提示词明确要求公式写普通字符；如果模型还是漏出来，欢迎提 issue。

**Q：想让它只做某个领域？**
A：在设置里把「系统提示词」改成一句话，或在「自定义术语」里加你的词表。内置提示词与术语表最初是为强化学习 / 机器人论文调的，翻译能力本身是通用的。

## 目录

```
app/                       Android 应用（标准 Gradle 布局，Java）
  src/main/java/…          MainActivity / 读屏服务 / 悬浮窗 / 模型调用 / 去重
  src/main/res/            图标、无障碍配置、字符串、快捷方式
  build.gradle.kts         命名空间 / 版本 / 可选环境变量签名
scripts/build-apk.sh       不依赖 Gradle 的手写构建（aapt2 + javac + d8 + apksigner）
docs/                      架构、提示词、构建说明
extras/dsh-plugin/         早期 DSH 网页插件原型，保留作参考
.github/                   CI（构建 APK + 打 tag 自动发 Release）、issue 模板
```

`extras/dsh-plugin/` 是同一套「读屏 → 视觉模型 → 去重 → 浮窗」逻辑的网页版实现，跑在 DeepSeek Harness 里，也能独立部署一个极简翻译页（`/rl-translator`）。它依赖 DSH 的内部服务，不建议单独使用，留作参考。
